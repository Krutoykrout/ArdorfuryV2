# Fury V2 Linux · 0.3.0

Неофициальное нативное Linux-приложение для проводной **ARDOR GAMING Fury V2
ARD-FRV2-3327-WT**, USB **04d9:a09f**, версия устройства **0307**.
Python + Qt + libusb; Wine и Windows-драйвер при запуске не нужны.

Реализована запись аппаратных макросов. Пользователь подтвердил запись и
воспроизведение сочетания клавиш на своей мыши. Остальные режимы требуют испытаний.

В 0.2.1 исправлены назначения цикла DPI и смены эффектов подсветки:
0.2 ошибочно отправляла DPI + и включение/выключение подсветки. После
обновления нужно применить вкладку «Основные», чтобы исправить назначения
в мыши. Макросы и значения DPI сохраняются. Пользователь подтвердил:
после исправления DPI снова переключается по кругу, а кнопка подсветки
перебирает эффекты.
Это экспериментальный выпуск, а не полный перенос всех функций Ardor.

## Новое в 0.3.0

- Во вкладке **Расширенные** работают системные настройки GNOME: скорость
  указателя, профиль ускорения и интервал двойного щелчка.
- В меню назначения кнопки добавлен готовый **Двойной клик**. Это отдельное
  действие мыши, не требующее создания макроса.

## Установка и запуск

Нужны Linux, Python 3.10+, PyQt6 и libusb-1.0. Для кнопки настройки доступа
нужны udev, polkit (`pkexec`) и активная локальная сессия.

Пример для Debian/Ubuntu:

```sh
sudo apt install python3 python3-pyqt6 libusb-1.0-0 pkexec
./install.sh
./run.sh
```

`install.sh` создаёт ярлык **Fury V2 Linux** в меню приложений. Если системного
PyQt6 нет, устанавливает его в локальную `.venv`; для этого нужны
`python3-venv`, pip и интернет. Установщик сам не меняет системные пакеты.
После перемещения папки повтори `./install.sh`, чтобы обновить путь ярлыка.

Приложение запускается от обычного пользователя. Если внизу окна нет доступа
к USB, нажми **Настроить доступ**: системный диалог установит точечное правило
udev для 04d9:a09f. При необходимости переподключи мышь. Устройство с другой
версией прошивки или несколько таких мышей одновременно не допускаются к записи.

## Что умеет

- Локальные профили: создание, переименование, импорт/экспорт JSON, сохранение.
- Шесть ступеней DPI 200–12400, число активных ступеней, цвета, выбор ступени;
  частота 125/250/500/1000 Гц. Выше 6200 прошивка кодирует DPI с шагом 200.
- 12 режимов подсветки, яркость, скорость, длина, цвет и палитра.
- Назначения семи кнопок: обычные клики, назад/вперёд, DPI, подсветка,
  отключение, двойной клик и макросы. Хотя бы один левый клик должен оставаться.
- Макросы клавиатуры и пяти кнопок мыши: запись в отдельном окне,
  ручное добавление/редактирование, перестановка, задержки, импорт/экспорт JSON.
- Режимы макроса: **заданное число повторов**, **до повторного нажатия**,
  **пока кнопка удерживается**. Повторы: 1–999.

## Настройки Linux

Во вкладке **Расширенные** блок **Настройки Linux · все мыши** читает реальные
значения текущего пользователя GNOME, отдельно от JSON-профилей устройства.
Поддерживается Ubuntu GNOME; в других окружениях этот блок отключён, остальные
функции приложения доступны.

- **Скорость указателя**: шкала −100…100, где 0 соответствует обычной скорости
  GNOME. Это коэффициент движения указателя, а не аппаратный DPI.
- **Ускорение**: системный профиль, без ускорения или адаптивное ускорение.
- **Двойной щелчок: интервал**: максимальная пауза между двумя кликами, чтобы
  приложение могло считать их двойным щелчком. Большее значение даёт больше
  времени на второй клик. Само по себе оно не создаёт второй клик; приложения
  и игры могут пользоваться собственными правилами обработки.

**Применить в Linux** записывает только отредактированные поля и проверяет
значения обратным чтением. Эти параметры действуют на все мыши текущего
пользователя и не сохраняются в памяти Fury V2. При сбое программа пытается
восстановить значения, прочитанные перед записью, и сообщает результат.
Заблокированные администратором параметры недоступны для редактирования.

**Прочитать из Linux** обновляет показания и сбрасывает неприменённые изменения
этого блока. Запуск, переключение профиля, импорт профиля и обычная кнопка
**Применить** не меняют системные настройки. Для блока нужен установленный
`gsettings`, схема `org.gnome.desktop.peripherals.mouse` и рабочее хранилище
настроек сессии. В Ubuntu GNOME они обычно уже присутствуют.

Скорость прокрутки остаётся недоступной: в используемой схеме GNOME нет такого
параметра. Задержка кнопок (debounce) также отключена, поскольку команда для
этой прошивки не подтверждена.

## Двойной клик одним нажатием

Открой **Основные**, нажми на назначение нужной кнопки и выбери **Двойной клик**,
затем **Применить**. Одна из кнопок должна сохранять обычный левый клик.
Существующее назначение выбранной кнопки будет заменено.

Это встроенное действие мыши, которое отправляет два левых клика. Пакет
сверен с одноимённым действием оригинальной программы. Физическое действие
на устройстве и реакция конкретных игр в этом выпуске ещё не проверены.

## Как записать макрос в мышь

1. Открой **Макросы**, нажми **+** и задай имя.
2. Нажми **Начать запись**, введи последовательность и закончи кнопкой
   **Готово** или Esc. Записываются только события в окне записи.
   Кнопка **Добавить** позволяет выбрать клавишу и сразу пару «нажать/отпустить».
3. При необходимости отредактируй задержки и число повторов.
4. Нажми **Назначить кнопке**, выбери кнопку и режим воспроизведения.
5. Нажми **Записать в мышь**. Отправляется вся таблица назначений кнопок
   активного профиля и все связанные с ней макросы. DPI и подсветка не меняются.

Нажатие и отпускание — два события. Лимит мыши: **40 событий и 128 байт**
на макрос, включая два байта числа повторов. Задержки свыше 1270 мс занимают
больше места. Индикатор показывает размер и причину, если макрос не помещается.
Данные не обрезаются молча. Все нажатия должны иметь отпускания; при завершении
записи зажатые клавиши автоматически получают события отпускания.

В профиле могут храниться более длинные черновики, но записать их в мышь
нельзя. Задержки кодируются с дискретностью оригинальной программы, точность
в миллисекунду не обещается. На X11 запись использует физические клавиши и
не зависит от русской/английской раскладки. На Wayland используется запасной
способ Qt; физическое соответствие клавиш и сторонние раскладки не проверены.
Esc завершает запись; чтобы включить Esc в макрос, добавь её вручную.
Колесо, перемещения мыши, мультимедийные клавиши и глобальная запись вне окна
пока не поддерживаются.

Для первого испытания удобно создать макрос из нажатия и отпускания **A**,
назначить боковой кнопке с одним повтором, применить и нажать эту кнопку
в пустом текстовом редакторе. Вывод символа зависит от раскладки ОС.
Затем можно проверить удержание, переключение и сохранение после переподключения.

## Сохранение и применение

Профили находятся в `$XDG_CONFIG_HOME/fury-v2-linux/profiles.json` или
`~/.config/fury-v2-linux/profiles.json`. Профили версии 0.1 читаются с сохранением
настроек; макросам добавляются постоянные идентификаторы для привязки кнопок.

Запуск, редактирование и смена профиля не отправляют настройки устройству.
**Применить** отправляет только открытую вкладку. Вкладки **Основные** и
**Макросы** обе записывают таблицу кнопок вместе с назначенными макросами.
Начальные значения профиля не являются прочитанными настройками мыши.
Назначенный макрос нельзя удалить, пока его кнопке не выбрано другое действие.

## Что ещё не подтверждено или не реализовано

- Режимы удержания/переключения макроса, точность задержек и сохранение
  после переподключения требуют испытания на устройстве.
- Успешная USB-передача не равна проверке применения: обратного чтения нет.
  При ошибке часть команд могла уже попасть в мышь.
- Скорость прокрутки и debounce не перенесены; соответствующие элементы
  отключены с объяснением. Системные настройки пока поддерживают только GNOME.
- Второй скрытый слой кнопок, специальные игровые функции и другие модели
  не поддерживаются. Размер окна фиксированный — 1280×750.

## Проверки

```sh
QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s tests -v
```

41 тест проходит: протокол, макросы, ограничения, миграция профилей,
назначения в интерфейсе, запись отпусканий и обработка ошибок USB.
100 эталонных конфигураций и 120 конфигураций макросов совпали с выводом
процедур оригинальной программы в изолированном эмуляторе. Кодирование
Feature Report отдельно проверено на 1003 входах. На подключённой мыши
проверено открытие и освобождение интерфейса №2 без записи настроек.
Есть GitHub Actions для запуска тестов без мыши. Дополнительно проверена
реальная запись трёх системных настроек и обратное чтение в отдельной сессии
D-Bus с временным хранилищем dconf; настройки пользователя не изменялись.
Тесты покрывают отказ записи, тайм-аут, откат, запрет изменения, независимость
системных настроек от профилей и USB, а также команду двойного клика.

Подробности: [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Оформление и исходники

Публичный архив использует собственные SVG и не содержит оригинальные
EXE/DLL, логотипы, картинки, профили пользователя или абсолютные пути ярлыка.
Локальная версия пользователя может использовать изображения из установленной
программы Ardor. Чтобы подключить свою копию темы:

```sh
python3 import-skin.py '/путь/к/папке/с/bk/и/mouse'
```

Импортируются только используемые картинки в
`~/.local/share/fury-v2-linux/skins` (учитывается `XDG_DATA_HOME`).
Перезапусти приложение. Локальная `assets/skins` имеет приоритет.

Код и собственные SVG распространяются под MIT, см. [LICENSE](LICENSE).
PyQt6 — отдельная зависимость со своей лицензией GPLv3 или коммерческой
лицензией; MIT этого проекта её не заменяет. Оригинальное оформление и
товарные знаки принадлежат правообладателям и в лицензию MIT не включены.
Проект не связан с ARDOR GAMING и не является официальным выпуском.

Основные файлы: `app.py` — интерфейс; `core.py` — профили и пакеты;
`macros.py` — компилятор макросов; `usb_device.py` — USB-транспорт;
`linux_settings.py` — системные настройки GNOME;
`setup-access.sh` — правило доступа. Программа не отключает драйверы
обычных кнопок и движения мыши и не обновляет прошивку.
